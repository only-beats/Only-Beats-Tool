How It Works guide
  1. Paste your track list in JSON format into the first textarea.
  2. Click "Check Duplicates" – the tool fetches your repo silently and compares titles.
  3. 🟢 New = not in your repo → download.
    🔴 Duplicate = already in repo – the Repo File column shows the matching `.mp3`.
  4. Use the Export buttons to copy results as JSON, CSV, or text table.
  5. If you need to extract tracks from a Spotify playlist, use the Spotdown Helper section above.
